# C-SIM — סימולטור טיסה

סימולטור טיסה תלת-ממדי של מטוס קרב ב-**Frontend בלבד** (HTML + JS + Three.js מ-CDN, ללא build וללא שרת).
ממריאים מבסיס נבטים, טסים מעל ישראל עם ערים/כבישים/שדות שנבנים דינמית,
וממשיכים לחקור את כל כדור הארץ — העולם עגול (חציית קו התאריך והקטבים עובדת).

## הפעלה

לפתוח את `index.html` בדפדפן (או שרת סטטי כלשהו, למשל `npx http-server`).
נדרש חיבור אינטרנט לטעינת Three.js מ-CDN.

## שליטה

| מקש | פעולה |
|---|---|
| ↑/↓ או W/S | פיץ' (משיכה = אף למעלה) |
| ←/→ או A/D | גלגול |
| Q/E | הגה כיוון |
| Shift/Ctrl | מצערת +/− |
| Tab | מבער אחורי |
| G / F / B | גלגלים / מדפים / בלמים |
| C | מצלמה (עוקבת / תא טייס / מגדל) |
| M | מפת עולם (עם ערפל גילוי) |
| T | האצת זמן ×2/×6/×15 |
| קליק במפת העולם | קביעת נקודת ניווט (WPT ב-HUD) |
| P / H / R | השהיה / עזרה / אתחול |

**מובייל**: ג'ויסטיק וירטואלי מימין, מצערת משמאל, כפתורי מערכות למעלה.

**המראה**: B לשחרור בלמים → מצערת מלאה (Shift) → ב-150 קשר משיכה (S/↓) → G להעלאת גלגלים.

## ארכיטקטורה (לצורך הרחבות)

| קובץ | תפקיד |
|---|---|
| `js/config.js` | קבועים: פיזיקה, קנה מידה עולם (`WORLD_SCALE`), צבעים + פונקציות עזר (`U`) |
| `js/geodata.js` | נתונים: פוליגוני יבשות, מדינות, ערי ישראל/עולם, אגמים (כנרת/ים המלח), שדות תעופה, כבישים |
| `js/aircraft.js` | מודל מטוס קרב מפרימיטיבים (`buildJet`) + מודל טיסה (`Aircraft`) — עילוי/גרר/הזדקרות/G/קרקע |
| `js/world.js` | מנוע העולם: צ'אנקים דינמיים לפי lat/lon, ביומים, בניינים (InstancedMesh), כבישים, כפרים, עצים, עננים, תוויות שמות, דיסק-מפה לגובה רב |
| `js/hud.js` | HUD מטוס קרב על קנבס 2D: סרגלי מהירות/גובה, סרט כיוון, סולם פיץ', FPM, אזהרות |
| `js/minimap.js` | מיני-מפה + מפת עולם עם ערפל גילוי ונתיב (נשמר ב-localStorage) |
| `js/controls.js` | קלט מקלדת + מגע |
| `js/main.js` | לולאת משחק, מצלמות, סאונד מנוע (WebAudio), ממשק |

### עקרונות מפתח

- **מיקום אמת**: המטוס מחזיק `lat/lon/alt` כ-double. הסצנה תמיד ממורכזת סביב המטוס
  (הצ'אנקים ממוקמים יחסית אליו כל פריים) — אין בעיות דיוק float והעולם "אינסופי".
- **דטרמיניזם**: כל תוכן נוצר מ-hash של קואורדינטות הצ'אנק — חוזרים לאותו מקום, רואים את אותה עיר.
- **מעגליות**: `U.wrapLon` + טיפול בקטבים ב-`Aircraft.update`. טסים מזרחה מספיק זמן — חוזרים לישראל.
- **קנה מידה**: `CFG.WORLD_SCALE = 1.0` = כדור הארץ בגודל אמיתי. אפשר להקטין כדי לקצר טיסות.
- **רמות פירוט**: צ'אנקים קרובים = בניינים ותוכן מלא; רחוקים = קרקע בלבד;
  מעל ~2.5 ק"מ גובה נכנס "דיסק העולם" שמציג את מפת היבשות האמיתית עד האופק.

### רעיונות להרחבה

חימוש ומטרות, מזג אוויר, לילה/יום, מטוסי AI, משימות (נווט אל...), תדלוק אווירי,
נחיתות מדורגות בשדות בעולם, טיסת מבנה מרובת משתתפים.
